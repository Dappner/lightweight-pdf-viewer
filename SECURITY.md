# Security

The app opens PDFs from anywhere, so a crash or worse from a crafted PDF is a security bug. Please report one privately through [GitHub's private vulnerability reporting](https://github.com/Dappner/lightweight-pdf-viewer/security/advisories/new) rather than a public issue, with the PDF if you can share it.

Pages are drawn and read by macOS's own PDF engine; bugs in it are Apple's to fix, and are best reported to them as well.
